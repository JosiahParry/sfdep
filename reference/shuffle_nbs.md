# Internal function to shuffle neighbors

Used in conditional permutation and the function
[`permute_listw()`](https://josiahparry.github.io/sfdep/reference/permute_listw.md).

## Usage

``` r
shuffle_nbs(i, n, card)
```

## Arguments

- i:

  the index position of observation `i`

## Value

a `nb` class object
