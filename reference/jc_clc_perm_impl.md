# Calculate CLC BV for conditional permutations

Calculate CLC BV for conditional permutations

## Usage

``` r
jc_clc_perm_impl(x, z, listw, index)
```

## Arguments

- x:

  a binary variable consisting of 1 and 0, or `TRUE` and `FALSE`.

- z:

  a binary variable consisting of 1 and 0, or `TRUE` and `FALSE`.

- listw:

  a `listw` object

- index:

  an integer vector identifying positions to subset.
